# Documentación

| Carpeta | Qué contiene | Cuándo se toca |
|---|---|---|
| `adr/` | Decisiones técnicas y su porqué | Al tomar una decisión que cambia el rumbo |
| `specs/` | Diseño del juego: reglas, brotes, enemigos | Al definir o cambiar una mecánica |
| `tasks/` | Trabajo a ejecutar, una task por archivo | Al planificar y al cerrar trabajo |
| `guias/` | Cómo se hace cada cosa: gráficos, animación, sonido, niveles gráficos, idiomas | Al pintar, animar o hacer sonar algo nuevo, al escribir un texto que ve el jugador, y al cambiar una convención |

## Orden de lectura

1. `specs/00-vision.md`
2. `specs/01-mecanicas.md` (incluye las decisiones pendientes)
3. `specs/02-brote-1-creeper.md`
4. `specs/03-ruta-de-brotes.md`
5. `specs/04-historia.md`
6. `tasks/README.md`
7. `guias/graficos.md` (antes de pintar, animar o hacer sonar cualquier cosa)
8. `guias/idiomas.md` (antes de escribir un texto que vea el jugador)
