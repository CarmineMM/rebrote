# Documentación

| Carpeta | Qué contiene | Cuándo se toca |
|---|---|---|
| `adr/` | Decisiones técnicas y su porqué | Al tomar una decisión que cambia el rumbo |
| `specs/` | Diseño del juego: reglas, mundos, enemigos | Al definir o cambiar una mecánica |
| `tasks/` | Trabajo a ejecutar, una task por archivo | Al planificar y al cerrar trabajo |
| `guias/` | Cómo se hace cada cosa: gráficos, animación, niveles gráficos, idiomas | Al pintar o animar algo nuevo, al escribir un texto que ve el jugador, y al cambiar una convención |

## Orden de lectura

1. `specs/00-vision.md`
2. `specs/01-mecanicas.md` (incluye las decisiones pendientes)
3. `specs/02-mundo-1-gusanos.md`
4. `tasks/README.md`
5. `guias/graficos.md` (antes de pintar o animar cualquier cosa)
6. `guias/idiomas.md` (antes de escribir un texto que vea el jugador)
